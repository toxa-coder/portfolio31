Информационные процесссы

Информационные процессы — это действия, выполняемые с информацией.
  • Получение информации. Биологические объекты и технические автоматы получают информацию об окружающем мире для принятия решений.
  • Хранение информации. Информация может многократно использоваться, а также иметь «отложенную ценность», то есть возможность быть потребленной не в момент получения, а с задержкой во времени.
  • Передача информации. Для этого процесса используются различные физические среды: колебания воздуха при передаче звука, электромагнитные волны для передачи световых и радиосигналов.
  • Обработка информации. В вычислительных устройствах процесс получения новой информации из уже имеющейся производится по строгим формальным правилам — алгоритмам.
  • Использование информации. Для целенаправленной деятельности объекты живой природы и созданные человеком автоматы, руководствуясь имеющейся в их распоряжении информацией, воздействуют на окружающую среду.

Получение информации — это совокупность действий, направленных на сбор сведений из разных источников.


Хранение информации – это процесс поддержания исходной информации в виде, обеспечивающем выдачу данных по запросам конечных пользователей в установленные сроки.


Передача информации – происходит при чтении книг, журналов, газет, при просмотре телевизора.


Обработка информации — это вся совокупность операций (сбор, ввод, запись, преобразование, считывание, хранение, уничтожение, регистрация), осуществляемых с помощью технических и программных средств, включая обмен по каналам передачи данных.


Использование информации – это процесс применения полученных данных для достижения определенных целей или решения задач. Когда информация получена и хранится, она может быть использована для различных целей в различных областях деятельности. Одним из основных способов использования информации является ее анализ и обработка.
